01

Why hand-built

A template starts from a layout made for everyone. A hand-built site starts from what your customers need to do on it.

  1. 1

    Built around your customers

    The page is laid out for the thing people come to do: call you, book, ask for a quote. Nothing is there because a template had room for it.

  2. 2

    Fewer parts to go wrong

    There is no theme or plugin stack to fall out of date. Fewer moving parts means fewer things that can quietly break.

  3. 3

    It is yours to keep

    You receive the code as plain files. You can host it anywhere, so you are never tied to one platform or one person.

05

Questions

Do I need any technical knowledge?

None. You tell me about your business and I handle the design, the code and the launch. If you want to edit content yourself later, a CMS means you never need to touch code.

What if I want something changed after launch?

Small content changes are covered by the optional care plan. Anything larger is quoted separately, so you know the cost before work starts.

Do I have to pay monthly?

No. The care plan is optional. Pay once for the build and host it wherever you like. The site is plain files with no server to run.

How long will it take?

It depends on how much content is involved. You get a date in writing when the scope is agreed. [Add typical timeframes here once you are happy to commit to them.]

Can you move my existing site across?

Yes. Migration is priced by the number of old addresses, and each one is mapped and redirected so links and search rankings survive the move.
